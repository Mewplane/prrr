# prrr Mobile Library

Cross-platform Rust core for prrr VPN mobile applications (iOS & Android).

## Overview

`prrr-mobile` is a shared Rust library that provides the core VPN functionality for prrr mobile clients. It uses [Mozilla's UniFFI](https://mozilla.github.io/uniffi-rs/) to generate type-safe Swift and Kotlin bindings, enabling code reuse across iOS and Android platforms.

### Architecture

```
┌─────────────────────────────────────┐
│   iOS App (SwiftUI)                 │
│   Android App (Jetpack Compose)     │
├─────────────────────────────────────┤
│   Swift Bindings   Kotlin Bindings  │  ← Generated by UniFFI
├─────────────────────────────────────┤
│   prrr-mobile (Rust)                │  ← This library
│   • Configuration parsing            │
│   • Connection management            │
│   • State tracking                   │
│   • Crypto (Noise + ML-KEM-768)      │
│   • QUIC/MASQUE transport            │
├─────────────────────────────────────┤
│   prrr core (Rust)                   │  ← Shared server/client code
│   • Handshake                        │
│   • Packet encryption                │
│   • Protocol logic                   │
└─────────────────────────────────────┘
```

**Key Design Principles:**
- **Shared Logic**: >85% code reuse between iOS and Android
- **Type Safety**: UniFFI generates safe, idiomatic platform bindings
- **Integration-First**: Leverages existing prrr codebase (handshake, crypto, transport)
- **No Platform Lock-in**: Rust core is platform-agnostic

## API Surface

### Configuration Management

**`VpnConfig`** - VPN configuration parameters
- Client name, server endpoint
- Cryptographic keys (X25519 + ML-KEM-768)
- Network settings (assigned IP, DNS, MTU)

**`parse_qr_config(qr_data: String) -> VpnConfig`** - Parse configuration from QR code

**`validate_config(config: VpnConfig)`** - Validate configuration fields

### Connection Management

**`VpnConnection`** - VPN connection manager
- `new(config: VpnConfig)` - Create connection with validated config
- `connect()` - Initiate VPN connection (async)
- `disconnect()` - Tear down VPN connection
- `status() -> ConnectionStatus` - Get current state
- `stats() -> ConnectionStats?` - Get connection statistics

**`ConnectionStatus`** - Connection state enum
- `Disconnected`, `Connecting`, `Connected`

**`ConnectionStats`** - Connection statistics
- Bytes sent/received
- Connection duration
- Server latency

### Error Handling

**`MobileError`** - Typed errors for all operations
- `InvalidConfig` - Configuration validation failed
- `ConnectionFailed` - Network connection failed
- `HandshakeFailed` - Cryptographic handshake failed
- `NetworkError` - General network error
- `NotConnected` - Operation requires active connection

See [docs/mobile-api.md](../docs/mobile-api.md) for detailed API documentation.

## Building

### Prerequisites

**General:**
- Rust 1.85+ with mobile targets
- `cargo install uniffi-bindgen` (for binding generation)

**iOS:**
- macOS with Xcode 15+
- iOS targets: `rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim`

**Android:**
- Android NDK (via Android Studio or standalone)
- Android targets: `rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android i686-linux-android`
- `cargo install cargo-ndk`

See [docs/mobile-build.md](../docs/mobile-build.md) for detailed setup instructions.

### Build Commands

**Build for all iOS targets (universal framework):**
```bash
./scripts/build-ios.sh
# Output: prrr-mobile/target/universal/prrr_mobile.xcframework
```

**Build for all Android targets (AAR):**
```bash
./scripts/build-android.sh
# Output: prrr-mobile/target/prrr_mobile.aar
```

**Generate Swift/Kotlin bindings:**
```bash
./scripts/generate-bindings.sh
# Output: 
#   prrr-mobile/bindings/swift/prrr_mobile.swift
#   prrr-mobile/bindings/kotlin/prrr_mobile.kt
```

**Run tests:**
```bash
cd prrr-mobile
cargo test
```

**Run linter:**
```bash
make lint
```

## Integration

### iOS Integration

1. Build the iOS framework:
   ```bash
   ./scripts/build-ios.sh
   ```

2. In Xcode, add to your project:
   - Drag `prrr-mobile/target/universal/prrr_mobile.xcframework` to project
   - Add generated `prrr-mobile/bindings/swift/prrr_mobile.swift`
   - Add `prrr-mobile/bindings/swift/prrr_mobileFFI.modulemap`

3. Import and use:
   ```swift
   import prrr_mobile
   
   let qrData = "prrr://import?config=..."
   let config = try parseQrConfig(qrData: qrData)
   let connection = try VpnConnection(config: config)
   try connection.connect()
   ```

See [examples/swift_example.swift](examples/swift_example.swift) for complete example.

### Android Integration

1. Build the Android library:
   ```bash
   ./scripts/build-android.sh
   ```

2. In Android Studio:
   - Copy `prrr-mobile/target/prrr_mobile.aar` to `app/libs/`
   - Add to `build.gradle`:
     ```gradle
     dependencies {
         implementation files('libs/prrr_mobile.aar')
     }
     ```
   - Copy `prrr-mobile/bindings/kotlin/prrr_mobile.kt` to `app/src/main/java/`

3. Import and use:
   ```kotlin
   import prrr_mobile.*
   
   val qrData = "prrr://import?config=..."
   val config = parseQrConfig(qrData)
   val connection = VpnConnection(config)
   connection.connect()
   ```

See [examples/kotlin_example.kt](examples/kotlin_example.kt) for complete example.

## Examples

### Swift (iOS)

```swift
import prrr_mobile

// Parse QR configuration
let qrData = "prrr://import?config=W2NsaWVudF0KbmFtZSA9ICJ0ZXN0Ig..."
do {
    let config = try parseQrConfig(qrData: qrData)
    print("✓ Parsed config for: \(config.clientName)")
    
    // Validate configuration
    try validateConfig(config: config)
    print("✓ Configuration is valid")
    
    // Create connection
    let connection = try VpnConnection(config: config)
    
    // Connect
    try connection.connect()
    print("✓ Connecting... Status: \(connection.status())")
    
    // Wait for connection (in real app, use polling or notifications)
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.2) {
        if connection.status() == .Connected {
            print("✓ Connected!")
            if let stats = connection.stats() {
                print("  Duration: \(stats.durationSecs)s")
            }
        }
    }
} catch let error as MobileError {
    switch error {
    case .InvalidConfig(let reason):
        print("✗ Invalid config: \(reason)")
    default:
        print("✗ Error: \(error)")
    }
}
```

### Kotlin (Android)

```kotlin
import prrr_mobile.*

// Parse QR configuration
val qrData = "prrr://import?config=W2NsaWVudF0KbmFtZSA9ICJ0ZXN0Ig..."
try {
    val config = parseQrConfig(qrData)
    println("✓ Parsed config for: ${config.clientName}")
    
    // Validate configuration
    validateConfig(config)
    println("✓ Configuration is valid")
    
    // Create connection
    val connection = VpnConnection(config)
    
    // Connect
    connection.connect()
    println("✓ Connecting... Status: ${connection.status()}")
    
    // Wait for connection (in real app, use coroutines or callbacks)
    Thread.sleep(200)
    if (connection.status() == ConnectionStatus.CONNECTED) {
        println("✓ Connected!")
        connection.stats()?.let { stats ->
            println("  Duration: ${stats.durationSecs}s")
        }
    }
} catch (e: MobileException.InvalidConfig) {
    println("✗ Invalid config: ${e.reason}")
} catch (e: MobileException) {
    println("✗ Error: $e")
}
```

## Troubleshooting

### Build Issues

**Error: `uniffi-bindgen` not found**
```bash
cargo install uniffi-bindgen --version 0.28
```

**iOS build fails with missing targets**
```bash
rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
```

**Android build fails with NDK errors**
- Verify NDK is installed: Android Studio → SDK Manager → SDK Tools → NDK
- Set `ANDROID_NDK_ROOT` environment variable

**Binding generation fails**
- Ensure library is built first: `cargo build`
- Check UniFFI version matches Cargo.toml: `uniffi-bindgen --version`

### Runtime Issues

**`parse_qr_config` throws `InvalidConfig`**
- Verify QR format: `prrr://import?config=<base64>`
- Check base64 encoding: must be URL-safe without padding
- Validate TOML structure matches expected format

**`connect()` returns immediately but never connects**
- This is expected stub behavior (Feature 1.5)
- Full QUIC connection will be integrated in future release
- Connection transitions to `Connected` after ~100ms simulation

**Clippy warnings in generated code**
- Generated UniFFI code may trigger clippy warnings
- These are suppressed in `src/lib.rs` with `#![allow(clippy::empty_line_after_doc_comments)]`
