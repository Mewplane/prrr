# FRD-M007: iOS Project Setup & Framework Integration

**Feature:** Feature 2.1 - iOS Project Setup & Framework Integration  
**Status:** Blocked - Requires macOS Environment  
**Created:** 2026-02-22  
**Phase:** Phase 2 - iOS Application  
**Predecessor:** FRD-M006 (Mobile Library Documentation)

## Overview

Create iOS application project structure with Xcode, integrate the prrr-mobile Rust framework, and configure necessary entitlements for VPN functionality.

## Motivation

Phase 1 delivered the complete Rust core library (`prrr-mobile`) with UniFFI bindings. Phase 2 requires creating native iOS application that integrates this library to provide VPN functionality to iOS users.

This feature establishes the foundation for all subsequent iOS development.

## Platform Constraint

**BLOCKING REQUIREMENT:** This feature requires:
- macOS operating system (version 13.0+)
- Xcode 15+ installed
- Apple Developer account (for signing and entitlements)
- iOS 15+ physical device for testing (VPN functionality doesn't work in simulator)

**Current Environment:**
- Linux (Fedora 6.18.10-200.fc43.x86_64)
- No Xcode available
- No iOS development tools

**Status:** Cannot be implemented in current environment.

## Goals

1. Create Xcode workspace with iOS app target
2. Add Network Extension target for VPN packet handling
3. Configure entitlements (Personal VPN, Network Extensions)
4. Integrate prrr-mobile.xcframework
5. Import Swift bindings generated by UniFFI
6. Configure App Groups for shared data between app and extension
7. Verify basic compilation and framework linkage

## Non-Goals

- Actual VPN functionality implementation (Feature 2.4)
- UI design (Feature 2.5)
- App Store submission (Phase 4)

## Requirements

### Functional Requirements

**FR-M007-01**: Create Xcode project
- Project name: "prrr VPN"
- Organization identifier: com.prrr.vpn
- Deployment target: iOS 15.0
- Interface: SwiftUI
- Language: Swift

**FR-M007-02**: Add Network Extension target
- Target name: "PacketTunnelProvider"
- Extension type: Packet Tunnel Provider
- Deployment target: iOS 15.0

**FR-M007-03**: Configure entitlements
- Enable "Personal VPN" capability
- Enable "Network Extensions" capability
- Create App Group: group.com.prrr.vpn

**FR-M007-04**: Integrate Rust framework
- Build prrr-mobile.xcframework using `./scripts/build-ios.sh`
- Add framework to both app and extension targets
- Set "Embed & Sign" for framework
- Add Swift bindings to project

**FR-M007-05**: Verify compilation
- Build app target successfully
- Build extension target successfully
- Verify Swift can import prrr_mobile module
- Run on iOS device (simulator won't work for VPN)

### Non-Functional Requirements

**NFR-M007-01**: Project SHALL follow iOS best practices

**NFR-M007-02**: Framework integration SHALL support universal binary (device + simulator)

**NFR-M007-03**: Entitlements SHALL be properly configured for App Store submission

### Framework Integration Steps

1. **Build Rust Framework:**
   ```bash
   cd /path/to/prrr
   ./scripts/build-ios.sh
   # Output: prrr-mobile/target/universal/prrr_mobile.xcframework
   ```

2. **Add to Xcode:**
   - Drag prrr_mobile.xcframework to Xcode project
   - Target Membership: both app and extension
   - Embed: "Embed & Sign"

3. **Add Swift Bindings:**
   - Copy prrr-mobile/bindings/swift/prrr_mobile.swift to project
   - Copy prrr-mobile/bindings/swift/prrr_mobileFFI.modulemap to project
   - Add to both targets

4. **Import in Swift:**
   ```swift
   import prrr_mobile
   
   // Verify it works
   let testConfig = VpnConfig(
       clientName: "test",
       serverEndpoint: "example.com:443",
       // ... other fields
   )
   ```
